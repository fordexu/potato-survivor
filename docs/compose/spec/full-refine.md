# 全面打磨 Full Refine

## Report

## [S1] Problem
初版《土豆幸存者》核心循环可玩，但相对「土豆兄弟」级精细度不足：
- 手感偏干：武器无朝向/后坐、命中反馈弱、Boss 无演出
- UI 缺层：无实时属性面板、无暂停、无帮助、商店看不出已有武器
- 内容偏薄：角色选卡不显示初始武器；无被动道具/套装；无锁定与合并提示
- 平衡粗糙：波次奖励与收获曲线偏平，后期缺乏策略纵深
- 视觉偏简：角色是纯椭圆，不是「像素土豆」观感

## [S2] Design

### S2.1 操作手感 Juice
- 武器环绕槽位固定角度分布；开火时朝目标方向偏转 + 后坐偏移
- 命中：敌人 hitFlash 延长、短 hit-stop（全局 timeScale 0.05s 内 ×0.25）
- 击杀：粒子加重 + 小范围屏幕 shake
- 受伤：红闪 + 无敌帧更明显（闪烁）
- Boss 登场：横幅 + 场地短暂变暗 + 弹幕前摇音
- 音效：按武器类型区分 shoot 音高；连续击杀有短促 pitch 上扬

### S2.2 UI/UX
- **实时属性面板**（Tab 按住显示 / 商店内常显侧栏）：当前 12 项属性数值
- **暂停**（Esc / P）：冻结更新，叠层显示属性与操作提示
- **帮助**：主菜单「玩法」按钮打开说明层
- **角色选卡**：显示初始武器图标与名称、关键加成数值
- **商店**：已有同类型武器时显示「已持有 · 购买将升级」；满 6 槽时提示
- **设置持久化**：localStorage 保存 mute 与最近角色
- **波次预览**：商店页显示下一波敌人类型图标

### S2.3 内容深度
- 新增 4 种被动道具（商店 kind=passive）：
  - 吸血牙：击杀回 1 HP
  - 重甲片：+8 护甲，-5% 移速
  - 弹药带：+12% 攻速
  - 赏金令：击杀额外 +1 材料（受收获加成）
- 武器合并规则明确：6 槽满时同类型购买 = 升级该武器；不同类型随机升级一件
- 角色差异展示强化：选卡列出 ± 属性
- 新增 2 个角色：
  - 僵尸土豆：死亡后一次复活（半血）
  - 赌徒土豆：暴击率 25%，暴击伤害 2.5，基础生命 5

### S2.4 数值平衡
- 波次奖励：`3 + wave*2 + harvesting*0.2`（略提高）
- 经验曲线：`xpNeed = 6 + level*5`（前中期升级更密）
- 敌人生命缩放：`1 + (wave-1)*0.15`；伤害缩放 `1 + (wave-1)*0.08`
- 精英与 Boss 材料掉落 +50%
- 商店价格随波次：`base * (1 + (wave-1)*0.06)`（原 0.08 略降）
- 拾取磁吸基础 100

### S2.5 视觉
- 角色改为 16×16 风格像素绘制（离屏 canvas 预渲染 sprite）：
  - 土豆身体 + 高光 + 眼睛 + 脚步帧
  - 敌人按类型不同形状/颜色/眼睛
- 武器图标在脚下阴影，开火 muzzle flash 点
- Boss 血条移到屏幕上方
- 场地角落增加暗角与随机砖纹

### S2.6 技术边界
- 保持无构建、纯静态 HTML/CSS/JS，file:// 可玩
- 不引入外部图片/音频资源；继续代码绘制 + WebAudio
- 不改动现有文件拆分边界；新逻辑优先并入现有 js 模块
- localStorage 键：`ps_mute`, `ps_last_char`

## [S3] Out of Scope
- 联网、账号、排行榜
- 成就系统、图鉴、剧情
- 移动端虚拟摇杆
- 外部素材包 / 精灵图导入
